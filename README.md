# عقلية | AQLIYA HQ — غرفة العمليات التكتيكية
### The Tactical Command Center & Second Brain for Projects, Intel & Strategy

---

## ⚡ نظرة عامة
**عقلية** هي منظومة تحكم شخصية تكتيكية فائقة الأمان والسرية، صُممت لتكون مركز قيادة لجميع مشاريعك وأفكارك واستراتيجياتك (بما في ذلك مشروع **NexusOS**) مع رادار معرفي تفاعلي، بنك استخباراتي لحفظ الفيديوهات والريلزات والحلول، ومستشار ذكي دائم بذاكرة تراكمية ومكالمة صوتية حية.

---

## 💻 تشغيل تطبيق اللابتوب (بدون Localhost وبدون متصفح):
التطبيق يعمل كبرنامج سطح مكتب حقيقي ومستقل (Native Windows Desktop App) دون الحاجة لفتح متصفح ويب أو خادم محلي:

1. **طريقة الاختصار المباشر (الأسرع):**
   - ستجد أيقونة التطبيق باسم **`عقلية - AQLIYA HQ`** على سطح مكتب جهازك أو داخل هذا المجلد.
   - انقر عليها مرتين وسيفتح التطبيق فوراً كنافذة مستقلة بدون أي شاشة سوداء أو أوامر.

2. **طريقة التشغيل الصامت:**
   - اضغط مرتين على الملف: `AQLIYA_HQ.vbs`

3. **طريقة الـ Terminal (للتطوير):**
   ```bash
   npm run app
   ```

## 📱 حزم وتحميل تطبيق الأندرويد (APK):
تم إعداد خط إنتاج آلي (GitHub Actions CI/CD) يقوم بتجميع وبناء ملف الـ APK السحابي:

1. **التحميل التلقائي عبر GitHub:**
   - بمجرد رفع هذا المستودع إلى حسابك في GitHub، ستعمل مهمة `Build Android APK` تلقائياً عبر سيرفرات سحابية مجهزة بـ Java 17 و Android SDK.
   - يظهر ملف **`AqliyaHQ-Android-v1.0.apk`** مباشرة في تبويب **Releases** أو **Artifacts** في حسابك على GitHub لتنزيله فوراً على هاتفك وتثبيته.

2. **البناء اليدوي المحلي:**
   - يمكنك فتح المشروع في Android Studio عبر الأمر:
     ```bash
     npx cap open android
     ```
   - أو تشغيل: `BUILD_ANDROID_APK.bat`

## 🛡️ أمان الحصن والمزامنة:
- **قاعدة البيانات:** PostgreSQL سحابية على **Supabase** مشفرة بسياسات Row-Level Security (RLS) ومربوطة ببث حي WebSockets.
- **القفل الرقمي:** رمز PIN الافتراضي `1337` أو عبر البصمة البيومترية.
- **التصدير الحر:** تصدير كامل بنقرة زر إلى **Obsidian Markdown Vault** و JSON بدون أي قيود.
- **العمل بدون إنترنت:** يدعم نظام `Offline-First` لتصفح وتدوين الأفكار والحلول دون اتصال بالإنترنت مع مزامنة تلقائية عند الاتصال.
